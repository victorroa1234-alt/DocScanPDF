Instalar en Android y consejos

Instalar como aplicación en Android

Al abrir esta web en Chrome desde tu teléfono (por HTTPS o localhost), toca el menú ⋮ → Instalar aplicación (o el botón Instalar arriba). Quedará como app en tu pantalla de inicio y funcionará sin internet.

Modos de nitidez para documentos

  • Documento Color: Limpia sombras y papel gris conservando firmas, sellos y colores.
  • Texto Nítido B&N: Realza el borde de cada letra y deja el fondo blanco puro. Ideal para apuntes, contratos y recibos.
  • Alto Contraste (Sauvola): Umbral adaptativo local para fotos con sombras fuertes o tinta tenue.
  • Grises: Escala de grises limpia para documentos con diagramas o fotografías.
